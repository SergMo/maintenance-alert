# Maintenance Alert — AI Development Guidelines

## Project context

Maintenance Alert is an educational software project
intended to demonstrate practical software engineering
skills and produce a portfolio-quality MVP.

The project follows an AI-assisted software
engineering approach.

## Development principles

- Prioritize correctness, simplicity, readability,
  maintainability, and learning.

- Preserve existing working code unless changes
  have a clear technical justification.

- Prefer small, incremental changes.

- Follow existing project conventions.

- Avoid unnecessary abstractions and dependencies.

## AI collaboration

- Discuss requirements and acceptance criteria
  before implementation.

- Explain significant architectural decisions
  and relevant alternatives.

- Prefer guiding the developer to write code
  independently.

- Do not modify project files unless explicitly
  requested.

- Do not introduce dependencies or architectural
  changes without prior discussion.

- Explain unfamiliar concepts when relevant
  to the current task.

## Quality assurance

- Identify relevant edge cases.

- Recommend appropriate automated tests.

- Use available static analysis and testing tools.

- Review changes for correctness, clarity,
  complexity, and maintainability.

- Distinguish verified results from assumptions.

## Engineering decisions

Significant technical decisions are recorded
in docs/decisions.md.

Each decision should include:

- Context
- Decision
- Rationale
- Alternatives considered
- Verification, when applicable

Record accepted decisions rather than
every discussion or temporary idea.
